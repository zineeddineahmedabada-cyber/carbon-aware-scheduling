# Carbon-Aware Workload Scheduling

A Python project to calculate, analyze, and compare carbon emissions associated with energy consumption throughout the day. It explores how variations in carbon intensity can influence the environmental impact of computing workloads and how scheduling tasks during lower-carbon periods can reduce emissions.

## Objectives
- Calculate CO₂ emissions based on power consumption, execution duration, and carbon intensity.
- Analyze variations in carbon intensity throughout the day.
- Compare baseline and carbon-aware workload scheduling strategies.
- Estimate emissions avoided and percentage reductions.
- Validate timestamped carbon data and detect stale observations using a configurable freshness threshold.

## Technologies
Python · Pandas · Unit Testing · Git

**Project status:** Experimental prototype using simulated carbon-intensity data. Integration with real-time carbon-intensity sources remains a future improvement.
